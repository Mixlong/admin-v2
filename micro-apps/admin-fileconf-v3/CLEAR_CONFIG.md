# 🔧 清除列配置缓存

由于修复了列配置的 BUG，需要清除浏览器中的旧配置。

## 方法1：使用浏览器开发者工具（推荐）

1. **打开开发者工具**
   - Windows/Linux: 按 `F12` 或 `Ctrl + Shift + I`
   - Mac: 按 `Cmd + Option + I`

2. **切换到 Console（控制台）标签页**

3. **复制并粘贴以下代码，然后按回车**

```javascript
// 清除列配置
localStorage.removeItem('shipment-order-columns')
console.log('✅ 列配置已清除')

// 刷新页面
location.reload()
```

## 方法2：点击"重置列配置"按钮

1. 刷新页面
2. 点击页面上的"重置列配置"按钮
3. 再次刷新页面

## 方法3：清除所有浏览器缓存

1. **Chrome/Edge**
   - 设置 → 隐私和安全 → 清除浏览数据
   - 选择"Cookie 和其他网站数据"
   - 点击"清除数据"

2. **Firefox**
   - 设置 → 隐私与安全 → Cookie 和网站数据
   - 点击"清除数据"

## 验证是否清除成功

清除后，打开浏览器开发者工具（F12），在 Console 中输入：

```javascript
localStorage.getItem('shipment-order-columns')
```

如果返回 `null`，说明清除成功！
