# IQC 品类不良统计报表

## 功能概述

IQC品类不良统计报表页面提供了全面的质量控制数据分析和可视化功能，帮助用户了解品类不良情况、供应商表现和趋势分析。

## 主要功能

### 1. 数据筛选
- **年份筛选**: 支持按年份查看统计数据
- **月份筛选**: 支持按月份查看详细数据
- **品类筛选**: 支持按产品品类进行筛选
- **供应商筛选**: 支持按供应商名称进行精确搜索

### 2. 统计概览
- **品类总数**: 显示当前筛选条件下的品类数量
- **供应商数量**: 显示涉及的供应商总数
- **不良总数**: 显示不良产品的总数量
- **不良率**: 显示整体不良率百分比

### 3. 数据可视化
- **品类不良分布图**: 饼图展示各品类的不良分布情况
- **供应商不良分布图**: 饼图展示各供应商的不良分布情况
- **每日趋势图**: 折线图展示每日不良数量变化趋势
- **每月趋势图**: 折线图展示每月不良数量变化趋势

### 4. 详细数据表格
- 显示品类、供应商、总数量、不良数量、不良率等详细信息
- 支持分页显示
- 不良率颜色标识（绿色：低风险，橙色：中风险，红色：高风险）

## API接口

### 1. 品类不良统计报表
```
GET /base/inventory/info/report/category
```
**参数:**
- `month`: 月份(yyyy-MM)
- `supplierName`: 供应商名称(精准搜索)
- `category`: 品类(精准搜索)
- `year`: 年份(yyyy)

### 2. 每日不良统计报表
```
GET /base/inventory/info/report/daily
```
**参数:**
- `month`: 月份(yyyy-MM) [必需]
- `supplierName`: 供应商名称(精准搜索)
- `category`: 品类(精准搜索)
- `year`: 年份(yyyy)

### 3. 每月不良统计报表
```
GET /base/inventory/info/report/monthly
```
**参数:**
- `year`: 年份(yyyy) [必需]
- `supplierName`: 供应商名称(精准搜索)
- `category`: 品类(精准搜索)

### 4. 供应商不良统计报表
```
GET /base/inventory/info/report/supplier
```
**参数:**
- `month`: 月份(yyyy-MM)
- `supplierName`: 供应商名称(精准搜索)
- `category`: 品类(精准搜索)
- `year`: 年份(yyyy)

## 使用说明

### 1. 页面访问
访问路径: `/iqc/statistics`

### 2. 数据筛选
1. 在页面顶部的搜索区域选择筛选条件
2. 点击"搜索"按钮应用筛选条件
3. 点击"重置"按钮清空所有筛选条件

### 3. 图表切换
- **品类/供应商切换**: 点击左侧图表上方的按钮切换显示品类统计或供应商统计
- **趋势类型切换**: 点击右侧图表上方的按钮切换显示每日趋势或每月趋势

### 4. 数据导出
点击表格区域右上角的"导出数据"按钮可以导出当前显示的数据

## 技术实现

### 1. 前端技术栈
- Vue.js 2.x
- Element UI
- ECharts (图表库)
- Axios (HTTP请求)

### 2. 组件结构
```
src/views/iqc/statistics/
├── index.vue          # 主页面组件
└── README.md          # 说明文档

src/api/iqc/
└── statistics.js      # API接口定义
```

### 3. 数据流
1. 用户选择筛选条件
2. 调用相应的API接口获取数据
3. 处理和转换数据格式
4. 更新图表和表格显示
5. 计算统计概览数据

## 注意事项

1. **数据权限**: 确保用户有访问IQC统计数据的权限
2. **性能优化**: 大数据量时建议使用分页和懒加载
3. **错误处理**: 网络异常时会显示模拟数据作为fallback
4. **响应式设计**: 页面支持不同屏幕尺寸的自适应显示
